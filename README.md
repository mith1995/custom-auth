# django-authnest

Reusable Django REST Framework authentication package.

- Login by email, phone or username (configurable for users and admins)
- JWT access and refresh tokens
- Email verification, forgot and change password
- Profile with picture, email change, account delete
- Optional soft delete

Status: alpha (0.1.0). Full documentation is coming soon.

## Install

    pip install django-authnest
